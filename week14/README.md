# Week 14 - UX & Refinement

## Frictions AI Identified
- Long, vague heading text made the feature unclear.
- Generic button labels ("Submit" instead of "Submit Name")
- Cramped spacing made the form feel crowded
- Initial status message didn't clearly set expectations 
- No visual emphasis (such as bolding) when a section was chosen


## Frictions I identified 
- Mobile header text cut off on more narrow screens (more specifically "questions" header)
- Scrolling on mobile devices takes a bit long (although I did not change that but will in the future by adding a collaspible cards feature to reduce scrolling).


## Improvements Made
1. **Clearer button labels:** For example, I changed "Submit" to "Submit Name" to make the button more clear and specific to this project.
2. **Better heading:** I shortened and simplified the header 1 for quicker understanding
3. **Initial feedback:** Changed status message to "Button not clicked yet" to set clear expectations
4. **Visual emphasis:** Made the chosen section name bold using `<strong>` tags so it popped out more.
5. **Added spacing:** Created the `.panel` CSS class with padding, margins, and styled form elements to make the page look much cleaner.
6. **Mobile responsiveness:** 
   - Stacked nav links vertically on narrow screens
   - Reduced the font size of the header.
   - Set input font to 16px for better accessibility
   - Adjusted nav spacing for phone-sized widths
