What is this site?

This website is a personal dashboard that I decided to create for a project in Web Foundations!

Why did I choose to do a Personal Dashboard?

I chose to create a personal dashboard because it sounded simple and not too complex. I also did not want to go too far from the basics since I am still learning how this works.

Why the color scheme?

I chose this (WIP) color scheme because I really like it, means something special to me, and it creates a pleasant visual experience.

Will you be updating this site after the project is due?

Hopefully, I would love to add more features and other content in the future!

What is your favorite part of this project?

My favorite part of this project is learning how to create a website and how to use HTML and CSS. I also like the fact that I can customize it to my liking and make it my own.

What is your least favorite part of this project?

My least favorite part of this project is that I am still learning how to use HTML and CSS, so it can be a bit frustrating at times. However, I am learning and getting better at it!

Why so many questions?

I included a lot of questions to provide a comprehensive overview of the project and to give visitor(s) a better understanding of what I was thinking and feeling throughout the creation of this website. And it is my website so I can :P
